# ZenBPM – v1.3.0

## Features

- Added message start events, including message start events of subprocesses.
- Added `timeCycle` timer definitions for timer start events.
- Added REST endpoints listing message, timer and error subscriptions.
- Upgraded the storage layer to rqlite v10.
- Added panic recovery to background goroutines, and structured goroutines in the cluster and partitions.
- Added an invoice approval acceptance test, and increased test coverage for user and service tasks.
- Added Trivy security scanning to the release process.

## Fixes

- A failed correlation key evaluation on a subprocess message start event now raises an incident.
- Multiline DMN entries are treated as quoted FEEL strings.
- Fixed the order of multi-instance outputs, and tightened propagation of activity outputs.
- Redeploying content that matches an older version creates a new process definition version.
- Fixed a missing history entry for error boundary transitions.
- The engine recovers from timer panics, and a process instance fails fast at start.

## Breaking Changes

- The `ProcessInstancesListItem` schema was replaced with `ProcessInstancesSimple` in the OpenAPI specification and the generated clients.
- Building from source requires Go **1.26**, needed by rqlite v10.
