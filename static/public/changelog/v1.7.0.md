# ZenBPM – v1.7.0

## Features

- Integrated GlitchTip (Sentry-compatible) error tracking and reporting across the core components.
- Improved performance with indexes for hot-path queries, pinned with `INDEXED BY` so new indexes cannot shadow them, and with indexed BPMN element lookup during token execution.
- Added change data capture (CDC) configuration and validation for rqlite partitions.
- Added validation of DMN definitions at deployment.
- The create process instance response includes `activeElementInstances` and the remaining instance parameters.
- Restructured the documentation into Getting Started and For Developers sections, added the first two Getting Started chapters, and updated the Java client documentation.

## Fixes

- Fixed race conditions, capacity tracking and round-robin selection in the job distributor.
- Fixed error propagation and token selection when a process instance is cancelled.
- Partition list endpoints return consistent responses, using `totalCount` for partition items.
- Fixed nested subprocess instance lookup.
- Handled all unhandled errors reported by code scanning and GoSec.

## Breaking Changes

- Partition list responses in the REST API changed to use `totalCount` for partition items. Update clients that read the previous response shape.
