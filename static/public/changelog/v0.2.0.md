# ZenBPM – v0.2.0

## Features

- Added boundary events on activities.
- Added DMN execution from BPMN processes.
- Added a job manager for distributing work to external workers.
  - Jobs can be completed and failed through the gRPC API.
  - Jobs are distributed round-robin on both the client and the server.
- Reworked message correlation, using message subscription pointers to find waiting process instances.
- Added pagination to the REST API, and handled duplicate deployments of the same process.
- Updated the REST API specification with examples.
- Added more metrics, with a ready-made Grafana and Prometheus setup, and CPU profiling endpoints.
- Added cluster change notifications for the controller.
- Updated protobuf definitions to edition 2023.
- Added release builds of ZenBPM binaries for Linux, macOS and Windows.
- Added licensing documentation and documentation for jobs and message correlation.

## Fixes

- Resolved a license compliance issue with the rqlite dependency.
- Fixed workers getting stuck and gRPC worker connection issues, and made the client work asynchronously.
- Fixed job variables not being persisted.
- Fixed minor errors in DMN evaluation.
- Fixed incorrect storage queries.
- Fixed flaky behaviour when stopping the timer manager.

## Breaking Changes

- The REST API now represents int64 keys as strings, so clients in languages without 64-bit integers do not lose precision. Clients that read or send keys as numbers must switch to strings.
