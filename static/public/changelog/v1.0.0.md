# ZenBPM – v1.0.0

## Features

- Released ZenBPM 1.0, the first stable version of the engine.
- Added embedded subprocesses and multi-instance activities, together with refactoring of the engine.
- Added terminate end events and a first implementation of error handling.
- Added an API to cancel a running process instance.
- Extended the REST API to support the community UI:
  - process definitions, with statistics per definition,
  - process instances, with filtering and sorting,
  - process instance variables management,
  - decision definitions, filtered by latest version, resource definition id or name,
  - decision instances, with filtering, sorting and lookup by key,
  - incidents and a reworked job API.
- Added an endpoint returning activity counts for BPMN processes.
- Saved history entries after gateways.
- Added Go and Java client documentation, and documentation pages for every supported BPMN element.

## Fixes

- Fixed a crash when running an instance that contains an unsupported business rule task.
- Fixed multi-instance execution, decision definition versioning and process versioning issues.
- Fixed refreshing of data in API methods and unmarshalling of decision outputs.
- Fixed locking of parent processes and missing batch clears in storage.
- Fixed several nil pointers and corrected error messages in the engine.

## Breaking Changes

- Decision instance responses no longer include `dmnResourceDefinitionId`, `dmnResourceDefinitionVersion`, `decisionRequirementsKey` and `decisionRequirementsId`.
- Decision instance lookups use `dmnResourceDefinitionId` instead of `decisionDefinitionId`.
- Protobuf property names changed from camel case to snake case.
