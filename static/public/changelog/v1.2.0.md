# ZenBPM – v1.2.0

## Features

- Added all three types of timer start events.
- Added error end events.
- Added error boundary events for failed jobs.
- Added panic recovery to the REST and gRPC servers, with a unified error response.
- Added search in process definitions and DMN resource definitions.
- Added sorting of process instances by `bpmnProcessId`, and sorting of history.

## Fixes

- Fixed variable mapping in multi-instance activities.
- An exclusive gateway now raises an incident when it evaluates an unknown value.
- Fixed processes getting stuck after a non-interrupting boundary event was triggered.
- Fixed missing active element instances in `GET /v1/process-instances`.
- Fixed duplicate rows in history and improved process instance statistics.
- Fixed a panic when deploying a second DMN with the same decision table id.
- Business rule task errors are propagated instead of causing a panic.
- The assignee of a job is preserved when the job is loaded from the database.

## Breaking Changes

- `POST /v1/process-definitions` is now idempotent: deploying an unchanged process returns **200** with the existing definition instead of **409 Conflict**.
