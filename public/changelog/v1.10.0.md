# ZenBPM – v1.10.0

## Features
- Support for BPMN Manual Tasks as pass-through activities that complete immediately without creating a job. Execution is recorded in process history, with support for variable mappings and sequential or parallel multi-instance execution.

## Breaking Changes
- Deploying or redeploying a model with a non-empty multi-instance completionCondition now returns 400 Bad Request. Previously, the condition was accepted but ignored. Remove it before redeploying; existing stored definitions continue to execute all iterations.
- Building from source now requires Go 1.27.3 or later.

## Fixes
- Requests referencing a nonexistent partition now return terminal errors once all configured partitions have formed: gRPC returns JOB_NOT_FOUND for job completion or failure, and LOCK_NOT_HELD for lock extension. REST returns 404 or an empty list, depending on the endpoint.
- Corrected the DMN OpenAPI schema: decisionOutput accepts any JSON value, including null; inputValue and outputValue explicitly allow null.
- Adapted CDC initialization to the updated rqlite API, preserving table filtering and row_ids_only delivery across partition restarts. Fixed SQL error detection and affected-row counting.

Maintenance
- Updated dependencies, including rqlite 10.6.6, gRPC 1.85.0, chi 5.5.0, and OpenAPI libraries.
- Expanded test coverage for Manual Tasks and multi-instance activities, including execution history, variable mappings, output collections, and isolation between iterations.
