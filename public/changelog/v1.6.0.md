# ZenBPM – v1.6.0

## Features

- Added monitoring with OpenTelemetry, including Grafana dashboards, graphs and alerting.
- Request bodies are validated against the OpenAPI specification.
- Embedded build metadata (version and commit) in the application and exposed it through REST endpoints, and added a version file validated against the OpenAPI version.
- Added `businessKey` to call activities and to expanded and collapsed subprocesses.
- Added end-to-end tests for message event scenarios.
- Added Discord notifications for security findings.
- Updated the Go toolchain to **1.26.5**.

## Fixes

- The health endpoint no longer reports READY before database initialization is complete.
- Cancelling a timer in the database also removes it from the timer manager.
- DRD input and decision mappings work when display names differ from identifiers.
- Multi-instance activities no longer create empty output variable keys or a phantom active history entry after the final iteration.
- Flow elements complete correctly in history during boundary and error events.
- Added the `application/xml` content type to the create process instance request specification.
- Increased the maximum size of the `getHistory` endpoint to **1000**.
- Development releases no longer get the `latest` tag.

## Breaking Changes

- Requests that do not match the OpenAPI specification are now rejected instead of being processed. Check clients that send extra, missing or mistyped fields.
