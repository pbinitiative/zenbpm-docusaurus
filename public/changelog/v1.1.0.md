# ZenBPM – v1.1.0

## Features

- Added message end events.
- Added multi-instance support to the REST API, and adjusted element statistics for multi-instance activities.
- Added a process instance statistics endpoint and a process definition statistics endpoint.
- Added `CreateProcessInstanceByBpmnKey`, and added `parentProcessInstanceKey` to the get process instance endpoint.
- Improved business key support.
- Parallelized partition queries for the instance and statistics endpoints.
- Standardized error handling across the REST API, covering process instances, DMN resource definitions, jobs, incidents, messages and partition persistence.
- Unified the OpenAPI UI.
- Optimized the job manager and data cleanup, and added foreign-key indexes and profiling endpoints.
- Added documentation for multi-instance activities, call activities, subprocesses, error handling and the Java client, and a local Docker configuration.

## Fixes

- Fixed processes failing to start when an expected variable was not provided.
- Fixed job completion and event correlation in subprocesses.
- Fixed non-interrupting boundary message events.
- Fixed boundary events and tasks inside loops.
- Fixed a variable shadowing bug in the variable context.
- Fixed a crash with unsupported business rule tasks, and removed panics from the BPMN engine.
- Migration errors now stop startup, explicit rollback scripts are supported, and migration scripts load correctly in Docker.
- Expired contexts are no longer passed into the engine, and graceful shutdown was improved.
- The business key is preserved when a process instance is saved.
- Fixed rqlite errors, token consumption and message publishing.
- Fixed potential nil pointers in cluster code and improved logging in the engine main loop.

## Breaking Changes

- REST endpoints return errors in a standardized error format. Clients that parse error responses must be updated.
