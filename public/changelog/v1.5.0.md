# ZenBPM – v1.5.0

## Features

- Added error start events in event subprocesses.
- Added automatic reconnection of gRPC worker streams.
- Extended flow element history with `completedAt` and `elementType`, and corrected completion history of flow elements.
- Stored activity variables from both the job and the process perspective.
- Added `elementInstanceKey` to the jobs REST endpoint.
- Added instance counts to process definition statistics and incident counts to the process instance list.
- Added load tests for the instance lifecycle and the invoice approval flow.
- Added goroutine leak detection to the end-to-end tests, and increased test coverage for DMN business rules and hit policies.
- Added a BPM concepts page and restructured the BPMN documentation.
- Introduced an orchestrated release process.

## Fixes

- Fixed a deadlock when an already cancelled boundary timer was triggered.
- Resolving an incident now reevaluates input variables.
- Child processes inherit the history TTL of their parent, and data cleanup handles errors better.
- Fixed a phantom active history entry after the final iteration of a multi-instance activity.
- Fixed goroutine leaks.
