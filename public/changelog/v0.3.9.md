# ZenBPM – v0.3.9

## Features

- Added new FEEL and JavaScript script runtimes, with a substantial rework of the DMN engine and fixes in the BPMN engine.
- Added process instance modification: tokens and variables of a running instance can be changed, using element instances.
- Added starting a process instance at a custom start point.
- Added business key support for process instances.
- Added time-to-live (TTL) support for process instance data.
- Added persistence of DMN decision instance variables.
- Added filtering of process instances by parent process instance.
- Added a generated REST client.
- Added Docker image builds to the release process.

## Fixes

- Fixed pagination in REST endpoints, including the missing total count for process instance jobs.
- Fixed call activities resolving references twice.
- Fixed a deadlock in the running instance cache.
- Fixed a nil pointer in the REST server.
- Fixed incident storage lookups by execution token.
- Removed `x-code-samples` from the OpenAPI specification and added the missing proto file to the deployment docs.

## Breaking Changes

- REST API keys are int64 numbers again instead of strings. Clients that send or read keys as strings must switch back to numbers.
- `decisionDefinitionId` was renamed to `dmnResourceDefinitionId`.
